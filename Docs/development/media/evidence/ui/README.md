# Native UI evidence

Rendered by actual SwiftUI/AppKit XCTest views on the M5 development Mac, in light/dark appearance and wide/narrow windows. Music uses an explicitly mocked API job and separate per-window drafts. Video shows the disconnected setup state and immutable local-image draft; this synchronous snapshot catches the asynchronous thumbnail while loading. No screenshot represents real model output, a hardware qualification or paid generation. Canonical input pixel/hash tests and real audio/video decoder/seek tests are separate.
